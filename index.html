Local Storage & Session Storage

HTML5 Web Storage provides key-value storage on the client side:

API Persistence Scope
localStorage Persists until explicitly deleted Per origin, shared across tabs
sessionStorage Cleared when the tab is closed Per tab, not shared 
// localStorage
localStorage.setItem('theme', 'dark');
const theme = localStorage.getItem('theme'); // 'dark'

// sessionStorage
sessionStorage.setItem('cartItems', JSON.stringify([{id: 1, qty: 2}]));
const cart = JSON.parse(sessionStorage.getItem('cartItems'));

Geolocation API

Access the user's geographic location (with permission):

if ('geolocation' in navigator) {
    navigator.geolocation.getCurrentPosition(
        (position) => {
            console.log('Latitude:', position.coords.latitude);
            console.log('Longitude:', position.coords.longitude);
        },
        (error) => {
            console.error('Error getting location:', error.message);
        },
        { enableHighAccuracy: true, timeout: 10000 }
    );
} else {
    console.log('Geolocation is not supported.');
}

History API

The History API allows manipulation of the browser session history, enabling single-page applications without full page reloads.

// Push a new state
history.pushState({ page: 1 }, 'Page 1', '/page1');

// Replace current state
history.replaceState({ page: 0 }, 'Home', '/');

// Listen for popstate (back/forward)
window.addEventListener('popstate', (event) => {
    console.log('State:', event.state);
});

12. Best Practices & Accessibility

Writing great HTML is about more than just syntax. Follow these guidelines to create robust, inclusive, and performant web pages.

Accessibility (A11y)

Accessibility ensures that people using assistive technologies (screen readers, switch devices, etc.) can interact with your content. Key practices include:

  • Semantic HTML: Use elements for their intended purpose. A
  • ARIA attributes: Use aria-label, aria-labelledby, aria-describedby, and role to augment semantics when native elements aren't sufficient.
  • Skip links: Provide a "Skip to content" link as the first focusable element on the page.
  • Color contrast: Ensure text has a contrast ratio of at least 4.5:1 against its background (AA level) or 7:1 (AAA level).
  • Keyboard navigation: All interactive elements must be reachable and operable via keyboard (Tab, Enter, Space, arrow keys).
  • Focus indicators: Never remove the :focus outline entirely. Custom focus styles should be even more visible than the default.
  • Alt text: Every must have alt. Decorative images can use alt="" (empty) to be ignored by screen readers.
  • Form labels: Every form control should have an associated element, either wrapping the control or linked via for / id.

Performance

  • Lazy loading: Add loading="lazy" to images and iframes below the fold.
  • Async/defer scripts: Use defer for scripts that need DOM readiness, async for independent scripts.
  • Preconnect: Use to warm up connections to critical origins.
  • Prefetch/prerender: Use rel="prefetch" for resources needed on future pages and rel="prerender" for the likely next page.
  • Inline critical CSS: Inline the CSS needed for above-the-fold content in the , load the rest asynchronously.
